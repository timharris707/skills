## Retro

**Retro**:
A review of a sample of past agent sessions in one repo that returns a short ranked list of fixes to the agents' environment, each labeled and routed to whoever owns the fix. The user picks which fixes happen; apart from adding a picked conduct rule to the user's rules file, the retro itself fixes nothing.
_Avoid_: retrospective (as the skill's name), post-mortem, session audit

**Critical**:
The retro label for an unsafe or irreversible action, or a leaked secret, even if it happened once.
_Avoid_: blocker, urgent

**Highly recommended**:
The retro label for friction that recurred in two or more sessions, or cost a review round or hours.
_Avoid_: high priority, important

**Recommended**:
The retro label for friction seen once that has a cheap, clear fix.
_Avoid_: nice to have, minor

**Worth considering**:
The retro label for a finding that is a judgment call rather than a clear fix.
_Avoid_: optional, low priority
