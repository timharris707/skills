# in-progress

Skills that are real enough to keep and not real enough to ship.

Nothing here appears in `.claude-plugin/marketplace.json` or on clickai.dev — that is the
point. Park a half-built skill here instead of leaving it half-wired into the catalog, and
`git mv` it into a promoted bucket when it earns its place.

CI enforces the boundary both ways: a skill in this bucket must not be claimed by any
plugin, and every skill in a promoted bucket must be.
